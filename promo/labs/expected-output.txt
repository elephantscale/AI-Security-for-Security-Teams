=========================
LOCAL SIMULATION | synthetic data | no model or network calls

Observed effect: cross-tenant disclosure in the unprotected simulation.
This is a scripted unsafe sequence, not a live model-injection result.

Demo 2: The resource enforces the boundary
==========================================
LOCAL SIMULATION | synthetic data | no model or network calls

Same unsafe read: Beta ticket B-1
  DENY: tenant_boundary | effect: none
Same unsafe send: B-1 to the external reviewer
  DENY: outside_task_scope | effect: none
Legitimate work: read Alpha ticket A-1
  ALLOW: within_policy | effect: record_read
Legitimate work: draft the Alpha response
  ALLOW: within_policy | effect: draft_created
  Summary-task outbox: 0 messages

Operator creates a NEW task: send A-1 to alpha-review@example.invalid.
Try an unapproved destination with the new grant
  DENY: destination_boundary | effect: none
Send the authorized record to the approved reviewer
  ALLOW: within_policy | effect: message_sent

Result: unsafe paths denied; authorized read, draft, and approved send succeed.

Demo 3: Stop and revoke are separate
====================================
LOCAL SIMULATION | synthetic data | no model or network calls

Stop worker, then try its queued draft
  DENY: worker_stopped | effect: none
Reuse its issued credential directly at the resource
  ALLOW: within_policy | effect: record_read
  Stopping the worker did not revoke its credential.

Revoke authority, then replay the same credential
  DENY: task_revoked | effect: none
Revoke a second task while its worker is still running
  DENY: task_revoked | effect: none
Check an unrelated authorized task
  ALLOW: within_policy | effect: record_read

Result: stopped execution, revoked authority, and checked downstream effects.
